    <h1>Usando API</h1>
</div>

---

O campo **Set Form Field** no FlutterFlow é uma Action (ação) usada para alterar ou preencher dinamicamente o valor de um campo de texto (como um TextField) via lógica da aplicação, sem que o usuário precise digitar manualmente. *Função Principal*: Definir o conteúdo de um campo de formulário com base em uma fonte de dados externa (resultado de uma API, banco de dados, cálculo ou variável local).

**Widget State**: É o valor atual contido nos elementos interativos da sua tela. Use quando precisar ler o texto que o usuário digitou em um TextField, o estado de um Checkbox (verdadeiro/falso), a opção marcada em um DropDown ou a data de um DatePicker.

**Action Outputs**: É o resultado retornado por uma ação que já foi executada no fluxo. Use para pegar a resposta de uma chamada de API (como o JSON da busca de CEP), o retorno de uma busca no banco de dados, o resultado de um Custom Code ou o upload de um arquivo.
